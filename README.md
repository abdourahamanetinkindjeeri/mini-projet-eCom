# Mini-projet eCommerce

Ce projet est une application e-commerce réalisée avec React.

## Fonctionnalités principales

- Affichage d'une liste de produits avec image, prix, stock et spécifications
- Filtrage des produits par plage de prix
- Ajout et retrait des likes sur chaque produit
- Gestion du stock (achat 1 ou 2 produits)
- Affichage dynamique du stock et de la disponibilité
- Comptage des vues sur les spécifications d'un produit

## Installation et lancement

1. Installer les dépendances :
   ```bash
   npm install
   ```
2. Lancer le serveur de développement :
   ```bash
   npm start
   ```
3. Accéder à l'application sur [http://localhost:3000](http://localhost:3000)

## Structure du projet

- `src/components/` : composants React (ProductCard, ProductList, FilterPrice...)
- `src/data/products.js` : données des produits
- `src/styles/` : fichiers CSS
- `public/` : fichiers statiques

## Scripts disponibles

- `npm start` : lance l'application en mode développement
- `npm test` : lance les tests unitaires
- `npm run build` : génère la version de production
